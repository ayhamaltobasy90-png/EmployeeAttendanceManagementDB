Employee Attendance & Management System (Database Project)
Designed and implemented a foundational Database Management System for employee administration.
The project handles core operational data, including employee details, departments, salary structures, manager hierarchies, check-in/check-out tracking, 
and attendance logs.
In addition to data modeling, I focused on database security, user access control, 
and query optimization. This project marks a key milestone in my GitHub portfolio, 
and I am currently expanding it into a full-stack application by building a robust backend API,
a dynamic frontend, and integrating full database functionality.
